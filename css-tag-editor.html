Wiki 代码 三个同时显示

固定三行，与下方 Tab 无关，始终同时输出颜色1 / 颜色2 / 颜色3；只列出与默认样式不同的声明，未改动的属性不会出现。背景恒排在参数第一位，且一律不带 background: 前缀、直接写值（wiki 不认这个前缀，误写了也会自动去掉），其余声明各占一行。可直接编辑：改这里预览与完整 CSS 同步，删掉某一行即把该项恢复为默认值（首行直接写背景值，如 #39c5bb 或 linear-gradient(...)）。右侧「全局」模式下，三行会合并成同一份公共样式（后写的覆盖先写的）再同步给三个矩形。

完整 CSS 代码 三个标签同步

全局编辑中：下面所有样式改动都会同时应用到「演唱 / P主 / 投稿」三个矩形；点任意矩形或上方标签即可切回单独编辑。文本内容保持各自独立。建议先在全局编辑处定好框架再分别编辑各栏。

每个颜色由四部分组成：色块（点一下打开取色器）· 十六进制框（可直接粘贴色值）· 「透」（一键切成 transparent）· 吸管（先在预览区导入一张图片，再点吸管、到图上任意位置点击取色；取色期间按 Esc 退出）。
