# 图标放这里

| 文件 | 说明 |
| --- | --- |
| `icon.png` | **图标源文件**（960×960，透明底）。要换图标就替换它，然后重新打包（双击 `build.bat`，或 `python build.py`）。 |
| `icon.ico` | 打包时自动生成的产物（16/24/32/48/64/128/256 多尺寸），不用手动维护。 |
| `icon.jpg` | 最初保存的原始素材：JPG 存不下透明通道，原来的透明底被压成了白灰棋盘格，**已不使用**，可以删掉。 |

打包时（`build.bat` / `python build.py`）的处理顺序：

1. 在 `assets/` 里按 `icon.png` → `icon.ico` → `icon.jpg/jpeg/webp` 找图标；
2. 非 `.ico` 的用 Pillow 转出多尺寸 `icon.ico`（非正方形的图先按中心裁成正方形，不会被挤扁；
   想完整保留画面就自己先裁成正方形）；
3. Windows 上用 `--icon` 把图标嵌进可执行文件；
4. 一个都没有时照常打包，只是 exe 用默认图标，终端会提醒一句。

⚠️ 图标图片请存成 **PNG**：JPG 存不下透明通道，透明区域会被压成棋盘格，做成图标就是一个棋盘格方块。
