# Vocawiki-create-tool Vocawiki条目辅助工具

Automatically generates Wikitext for Japanese VOCALOID songs, tailored specifically for the [Vocawiki](https://voca.wiki/). If you are not a Chinese speaker, this project is probably useless to you.

本程序用于生成自动[Vocawiki](https://voca.wiki/)的日语VOCALOID歌曲条目。本仓库主体代码来自于[MGP-VJ-tool](https://github.com/lihaohong6/MGP-VJ-tool)，并在此基础上修正了一些bug并添加新功能。

## 启动方法

从[releases](https://www.github.com/TimeRen/Vocawiki-create-tool/releases) 下载、解压后运行 `Vocawiki-create-tool`。

左侧竖栏：

- **功能**：选「生成歌曲条目」「生成P主模板」「生成歌姬模板」；切功能会把当前这一轮停掉、界面复位。
- **头像**：点一下登录 Vocawiki（再点可重新登录 / 退出登录 / 改账号密钥）。
- **齿轮**：打开「设置」页。

右侧标签页（「样式」「歌词」「曲目」「提交」平时是灰的，流程走到那一步自动点亮并切过去）：

| 标签页 | 做什么 |
| --- | --- |
| **填写信息** | 按提示在下方输入（输入框 / 整段粘贴 / 选项按钮）；「清空」只清当前输入（Ctrl+L），「确定 / 完成」提交 |
| **日志** | 看网络请求、上传进度、错误与 `print` 输出 |
| **样式** | 调歌曲配色或模板配色 |
| **歌词** | 整理歌词 |
| **曲目** | 改曲目 / 专辑清单 |
| **提交** | 预览 / 编辑 / 提交到 Vocawiki |
| **设置** | 点齿轮才出现，保存成功或切走自动收回 |

底部状态栏显示当前走到哪一步；窗口拖窄时当前页会自己出滚动条。

纯终端用法：`Vocawiki-create-tool --console`；模板两条流程是 `--console --producer`（P主模板）与 `--console --vocalist`（歌姬模板）。

## 生成歌曲条目（侧栏第一个功能）

1. 侧栏「**功能**」选「生成歌曲条目」。
2. 「填写信息」页依次回答：**日语曲名**（必填）→ **中文曲名**（与日语相同或没有翻译就留空）→ **B 站视频链接**（如有；支持 `b23.tv` / `bili2233.cn` 短链，指向图文而不是视频时会让你重填）。
3. 参加了 The VOCALOID Collection 时不用填赛道与名次（程序自己读那一届的活动模板）；读不到才问，那时选 TOP100 / ROOKIE / REMIX / 榜外。
4. 「样式」页调 Songbox / Introduction / 歌词 三段颜色（自动载入封面、可用吸管取色，每项都能单独「输出」或关掉）。
5. 需要手动提供歌词时在「歌词」页整理（见「歌词页」）。
6. 「提交」页实时预览、手改，点「**提交到 Vocawiki**」：上传封面 → 创建/更新条目 → 创建重定向；失败时状态栏变红，改完按 `Ctrl+Enter` 重试。

要用到的开关（改 `config.yaml`，或点齿轮在设置页里勾）：

| 开关 | 打开后 |
| --- | --- |
| `wikitext.uploader_note` | 询问投稿文（多行输入，空行结束） |
| `wikitext.human_original` | 多问一句「是否存在人声本家」（同一首歌的人声演唱版本）；回答「是」再依次要 niconico / YouTube 链接与 bilibili 链接，都可留空跳过 |
| `wikitext.other_versions`（默认开） | 从 VocaDB 列出同一首歌的翻唱 / 改编版本让你挑，再问该版本的 bilibili 链接与「B 站投稿是P主自己提交的吗」 |
| `wikitext.lyrics_chs_fail_fast` | 找不到中文翻译时直接放弃，不弹歌词页 |
| `wikitext.furigana_all` | 给歌词里没写读音的汉字标 `{{photrans|汉字|假名}}`（用 AI） |
| `image.download_cover` | 下载封面并随条目上传 |
| `image.crop`（默认开） | 裁封面黑边 |
| `wiki.submit_window` | 生成后切到「提交」页，而不是用 VS Code 打开输出文件 |
| `wiki.disambiguate`（默认开） | 处理同名条目（见下） |
| `wiki.create_redirect` | 额外创建「日文原名 → 中文条目」的重定向 |
| `wiki.edits_per_minute`（默认 3） | 提交编辑的频率上限（平均每 `60 / N` 秒一次，`0` = 不限制） |

⚠️ 关掉 `wiki.submit_window` 封面就不会上传（提交页是本工具**唯一**的图片上传入口）。

### 同名条目（`wiki.disambiguate`）

开着时程序全自动处理（条目名与封面文件名改成「歌名(P主名)」、顶部加消歧义模板、把占用裸标题的那首歌移到它自己的后缀下、在裸标题上建消歧义页）。你要做的只有：

1. 移动后弹出的「**修正链入页面**」窗里勾选要改的页面；
2. 点「**替换选中页面的链接**」。

账号需要有**移动页面**权限。

## 样式页

- 左边两个文本框可以直接手写，**切标签、改右边控件都不会覆盖**：`Wikitext 参数`（三块颜色 + 模板参数）点「**从文本载入**」解析回模型，`完整 CSS（可编辑）` 点「**应用代码**」应用进模型。只有点「重置当前 / 重置全部」「用 AI 生成」或开始新一轮生成才会重新生成。
- 右侧「**辅助工具（测量 / 参照物）**」只是屏幕上的尺子，不写进 wikitext：点「开始测量」后在预览台或封面图上点两下量距离；选好线段 / 矩形与角度、宽高后点「开始放置」再在画布上点一下放一个。`Esc` 或右键退出工具模式，与取色吸管互斥。
- 「AI 参考封面生成 CSS」按钮见「AI 配色与密钥」。

## AI 配色与密钥

1. 在 `wiki_credentials.yaml` 里填好 AI 接口（预设 DeepSeek-V4.1-Flash，也可填 `anthropic` 用 Anthropic 消息接口）：

```yaml
ai_provider: "openai"                          # openai = OpenAI 兼容接口
ai_base_url: "https://api.deepseek.com/v1"     # 换服务商改这里
ai_model: "deepseek-flash"                     # 必须支持看图
ai_api_key: "sk-..."
ai_thinking: false                             # 仅 DeepSeek：是否开思考模式
```

2. 「样式」页点「**AI 参考封面生成 CSS**」（歌曲条目 / P主模板）或「**AI 配色**」（P主模板 / 歌姬模板）：把封面图与当前样式发给能看图的 AI，它给出 CSS 并直接应用；不满意点「**撤销这次生成**」。
3. 生成前可改「**生成范围**」（默认当前编辑对象，也可一次全生成）与「**只改颜色**」（勾了不许 AI 碰尺寸 / 字号 / 间距）；「补充要求」按对象预填 `color.ai_prompt_songbox` / `ai_prompt_intro` / `ai_prompt_lyrics`。

`ai_api_key` 为空时按钮置灰；`color.ai_css` 设为 `false` 则整个 AI 面板不显示。同一套密钥也给这几处用：

| 用在哪 | 开关 |
| --- | --- |
| 歌词页「AI 识别并填入」 | `wikitext.ai_lyrics` |
| 曲目页「AI填充中文名」 | `wikitext.producer_names` |
| 歌词「AI 生成振假名」 | `wikitext.furigana_all` |

## 设置页（可视化改配置）

1. 点侧栏底部的**齿轮**（或点头像进的菜单）打开设置页；它才会出现在标签栏上，保存成功或切走自动收回。
2. 分组：**基本**（界面语言、应用字体、输出目录、保存输入、代理、字号缩放）、**生成内容**（各项 wikitext / 封面开关）、**样式编辑器**（是否启用样式页、是否显示 AI 面板、AI 三栏提示词）、**封面图片**（下载封面、裁黑边）、**Vocawiki**（API 地址、速率墙、提交页、日文重定向、同名条目处理）、**账号与密钥**（`username` / `password` / AI 接口与密钥）。
3. 想先试别人的配置：点右上角「**导入配置文件**」选 `config.yaml` / `wiki_credentials.yaml`（按内容自己认是哪种，只改界面不写盘），确认无误再点「**保存**」。
4. 点「保存」写回两个文件并立即重新载入（输出目录 / 保存输入这类在流程开始时读一次的，下次运行才生效）；写回是就地改值，注释与顺序都保留。
5. 保存失败看底部红字与「日志」页；改界面语言要重启程序。

## 歌词页（手动整理歌词）

自动找不到中文翻译时会问是否手动输入（想直接放弃就设 `wikitext.lyrics_chs_fail_fast`）；选「是」后自动切到**「歌词」页**（本曲歌姬会一起带过来）。

1. 左边粘整段歌词（日语 / 中文 / 罗马音混排也行）。
2. 点「**自动识别并填入**」按语言分栏；都认不出来时它会给一套「每组行数 + 各语言行号」，再点「**按行号转换**」切分。
3. 排版很乱（带编号 / 时间轴 / 混排）时点右上角「**AI 识别并填入**」交给大模型分栏（只分栏，不翻译不改写；开关是 `wikitext.ai_lyrics`）。
4. 四栏都可手改；鼠标悬停某一行时，四栏里的同一行会一起高亮。
5. 填好「**来源链接**」后点「**从链接填充**」自动补翻译者 / 翻译链接 / 来源（只覆盖读到的字段，失败会在状态栏说明）；能认网易云歌曲、bilibili 视频 / 评论 / 专栏 / 动态 / 短链、巴哈姆特創作大廳。
6. 点「**完成**」返回整理好的歌词（日语与中文不能同时为空）；「取消」放弃编辑。

### 演唱者上色（`LyricsKai/colors`）

1. 在「歌词」页底部勾选「**使用 LyricsKai/colors（演唱者上色）**」，歌词改用 `{{LyricsKai/colors}}` 输出（颜色照 voca.wiki 的 [`Module:Vocalist_Colors`](https://voca.wiki/Module:Vocalist_Colors) 取，charas 是本曲歌姬）。
2. 在下方「**歌唱者标记**」面板里点亮某一行右边的歌姬按钮 = 这句是 Ta 唱的（一行可点多个，底色就是该歌姬的颜色）。
3. 左上角「**标记栏**」切日语栏 / 中文栏；两栏标记各存各的，「清空本栏标记」只清当前栏。
4. 两栏行数不一致时点「**按日语标记中文**」照搬（交给 AI 对齐行号，需要 `ai_api_key`）。
5. 一句里几个人各唱一半时，把光标放在要切开的位置点「**切开**」；点「**合并**」收回切口。

也可以单独运行`python parse_lyrics.py`，只打开「歌词」页并打印生成的歌词段落。

## 提交页（条目 / 模板通用）

1. 左边直接改生成的 wikitext，右边实时预览（在预览里点右键有中文菜单）。
2. 点「**提交到 Vocawiki**」（或 `Ctrl+Enter`）：上传封面 → 创建/更新条目 → 创建重定向，并把结果写回本地文件；需要登录（见「账号配置」），未登录时只能预览与编辑。
3. 结果一条一条弹在右下角；提交失败时状态栏变红、窗口保持打开，改完可以再按一次。
4. 「**同步大家族模板**」开关（默认开）：提交成功后把这首歌写进 `== 注释 ==` 里那些模板的对应小节（点开先显示一份「准备怎么改」的说明，结构认不出就跳过）。
5. 已下载封面时，提交前会问一句封面中出现的歌姬（用于生成文件说明页的分类）。

## 生成P主模板（侧栏第二个功能）

1. 侧栏「**功能**」选「生成P主模板」（终端模式：`Vocawiki-create-tool --console --producer`）。
2. 按提示给 P主名 / id / `https://vocadb.net/Artist/Details/<id>`（曲目与专辑都取自 VocaDB，年份按**稿件投稿日期**算）。
3. 「曲目」页核对：左边年份列由投稿日期算出，中文条目 / 日文原名 / 投稿日期都能直接改；右边「状态」列显示条目**已建 / 待建**，可点「刷新条目状态」重查；专辑是单独一列清单。
4. 补中文名（都只动**还没中文名**的曲目；「从维基补全条目名」不受开关控制，后两个由 `wikitext.producer_names` 控制）：
   - 「**从维基补全条目名**」：按日文原名搜 voca.wiki，要它自带信息框、自己声明这个歌名；同名但是别人的歌写成 `名字(P主名)`；
   - 「**从外部链接获取中文名**」：网易云 + bilibili 搜日文原名；
   - 「**AI填充中文名**」：问大模型，回来逐个弹窗复检（框里可直接改，「采用并下一个」按改后的写）。

   实在补不出来就在表格里手填（模板里写红链是正常的）。

5. 「样式」页调三组颜色（标题栏 / 分组栏 / 列表 → `{{Navbox}}` 的 `titlestyle` / `groupstyle` / `liststyle`；每格都有「默认」按钮 = 这一项不写）；参考图默认是 P主头像（打开这页自动下载），想换点「选择参考图…」，点「AI 配色」照图配色。
6. 「提交」页点「提交到 Vocawiki」（提交对象是 `Template:<P主名>`，页名 / 模板名能在「曲目」页改）。
7. 提交成功后的弹窗：勾选「把 `{{<模板名>}}` 加进模板链接的条目」（P主条目排在最前，后面是模板里 `{{links|…}}` 列出的曲目），确认后逐页写入；已经写过的条目跳过，看着不像歌曲条目的页会灰掉。

## 生成歌姬模板（侧栏第三个功能）

1. 侧栏「**功能**」选「生成歌姬模板」（终端模式：`Vocawiki-create-tool --console --vocalist`）。
2. 按提示给歌姬名（**维基上的条目名**，例如 `歌爱雪` / `重音Teto`）→ 选生成方式 → 选「不拆」时再选一次「其他」栏怎么排：

| 生成方式 | 生成的页面 |
| --- | --- |
| **拆成年份子页，并重写主模板**（默认） | 年份子页 + 文档 + 主模板 |
| **只新建年份子页，不动既有主模板** | 只有年份子页（既有主模板原样不动） |
| **不拆，一个页面写完整** | 一个完整的主模板 |

「其他」栏的排法（选「不拆」时才问，之后还能在「曲目」页上随时勾选切换）：**平铺**（默认，`其他 → 曲目 • 曲目`）或**按年份分层**（`其他 → 2022年 / 2023年 → 曲目`）。拆成年份子页时每页年份已固定，子页里一律平铺。

3. 素材自动抓（歌姬所属引擎的殿堂页 + 分类 `Category:<歌姬>歌曲`）；拿不准的曲子会记进「待复核」，在「曲目」页点「**人工复核待定项**」一条一条过（栏 / 站点 / 年份都能改）。

4. 「曲目」页核对：栏 / 站点双击可改（站点写成 `niconico、YouTube`），「删除选中」去掉不该收的曲子，「恢复原样」撤销改动；下面写着会生成哪几个页面与主模板预览（「不拆」时预览那一行还有「**「其他」栏按年份分层**」勾选框）。
5. 「样式」页调三组颜色（与 P主模板共用同一页）；参考图默认是歌姬立绘，点「AI 配色」照它配。改写既有模板时会继承它的样式与「相关人物」那一栏，新建模板从空配色开始。
6. 「提交」页（多页面时顶部有页面选择器，顺序 = 提交顺序）：点「提交到 Vocawiki」（或 Ctrl+Enter）只交当前页，「**全部提交**」按顺序交完还没交过 / 交后又改过的页。
7. 提交成功的弹窗把 `{{<歌姬>/<年份>|collapsed}}` 写进曲子条目、把 `{{<歌姬>|nocate=1}}` 写进歌姬条目。

会生成这些页面（拆分时）：

```
Template:<歌姬>/2009 … /2026     ← 年份子页：只列这一年的曲子
Template:<歌姬>/doc              ← 模板文档
Template:<歌姬>                  ← 主模板：相关人物 + 各年份的转接行
```

⚠️ 注意：

- 分类里**最多处理 20000 首**，这个量级请配「只新建年份子页」用（不拆分时「其他」栏会有几千首）；
- 「只新建年份子页」模式下**子页不会自动挂到主模板上**，要自己把 `{{<歌姬>/<年份>|nocate=1}}` 加进去；
- 没有年份的曲子会进待复核，不处理就不会出现在任何页面里。

## 账号配置

1. 登录 Vocawiki，打开「参数设置 → 机器人密码」（或访问`Special:BotPasswords`）。
2. 创建一个机器人密码，授权至少勾选「上传新文件」「编辑现有页面」等权限。
3. 在`wiki_credentials.yaml`中填写（出于安全考虑，建议用**机器人密码**而非主账户密码）：

```yaml
# wiki_credentials.yaml
username: "你的账户名@机器人名"     # 例如 TimeRen@tool
password: "机器人密码"
```

未登录时仍可预览与编辑，只是无法提交。

## 自己构建（打包 exe）

Windows 上双击 **`build.bat`** 就能打包（先找 Python，优先项目自带的 `.venv`；缺依赖时自动 `pip install -r requirements.txt`，再调 `build.py`）：

```bat
build.bat 1.3.1      :: 直接打包 1.3.1
build.bat            :: 不带版本号时会问一次（回车用 0.0.0）
build.bat --check    :: 只检查 Python 与依赖，不打包
```

Linux / macOS 走同一个 `build.py`：

```bash
make build VERSION=1.3.1     # 或 make build（会问版本号）
make source                  # 源码包
./make_source.sh 1.3.1       # 同上，只是不开头走 make
python build.py 1.3.1        # 直接调脚本（依赖需已装好）
```

发布包只在项目根目录生成 `Vocawiki-create-tool (版本号).zip`（exe + 运行时资源，解压即用），两个包里的 `wiki_credentials.yaml` 都是**清空过密钥的模板**。程序图标放 **`assets/icon.png`** 即可，打包时自动转成 `assets/icon.ico` 并嵌进 exe。
